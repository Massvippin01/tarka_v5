# SENTINELX NEXUS — Synthetic Data Model Specification

## Overview

- **Deterministic Identifiers**: Aadhaar (`9988-1122-3344`), DL (`DL-1420190012345`), Phone (`+91-9999011223`), Registration (`DL-01-AB-1888`), UPI VPA (`vicky.mule@okicici`).
