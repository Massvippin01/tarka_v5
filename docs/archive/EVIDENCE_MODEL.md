# SENTINELX NEXUS — Evidence & Governance Model

## Evidence Pipeline Architecture
```
RAW RECORD ➔ OBSERVATION ➔ ANALYTICAL SIGNAL ➔ EVIDENCE ➔ VERIFIED CLAIM ➔ AI RESPONSE
```

## Ground-Truth Verification Standard
1. **Factual Claim Grounding**: Every factual assertion generated by the AI Copilot is deterministically resolved against `UnifiedStore`.
2. **Epistemic Classification**:
   - `FACT`: Ground truth matches authoritative store record. Marked `VERIFIED`.
   - `INFERENCE`: Derived from multi-feature analytical engine correlation. Marked `UNCONFIRMED`.
   - `HYPOTHESIS`: Competing explanation requiring human review.
3. **Investigator Verification Workflow**: Human investigators review AI claims and record explicit audit actions (`CONFIRMED`, `DISMISSED`, `REQUIRES REVIEW`) with review notes without silently mutating underlying source data.
4. **Audit Trail**: Every query, scope, tool execution, accessed record, and investigator verification decision is logged in `AuditService`.
