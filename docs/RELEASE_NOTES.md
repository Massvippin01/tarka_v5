## 1. Executive Summary

TARKA is an indigenous, voice-first digital forensics and evidence-analysis platform built for investigating complex financial, cyber, and multi-source discrepancy cases. This release delivers production-hardened multilingual conversational intelligence, deterministic mathematical constraint solving via Z3 SMT, cryptographic evidence bitstream preservation (SHA-256 CAS), and Section 63 Bharatiya Sakshya Adhiniyam (BSA) statutory report generation.

## 2. Key Enhancements & Root-Cause Fixes

### A. End-to-End Sarvam AI Voice Pipeline Fixed
- **Root Cause Resolved**: Identified that `bulbul:v4-flash` rejected the legacy/alias speaker identifier `priya_enhi_conversational` with HTTP 400. Mapped speaker aliases server-side to verified v4 catalog personas (`simran_enhi_companion`, `shubh_enhi_ads`, `gokul_ta_narration`, `kavitha_te_narration`, `arnab_bn_conversation`).
- **Timeout Extension**: Increased backend synthesis socket timeout from 4.0s to 25.0s and frontend Axios timeout from 10.0s to 35.0s, accommodating neural synthesis latency (~8–12s) without network drops.
- **Bounded Chunking**: Capped speakable audio text to 450 characters to prevent excessive generation latency.
- **Protected Diagnostic Telemetry**: Added sanitized status reporting to `GET /api/v1/forensics/sarvam/status`, categorizing failures into `AUTH_ERROR`, `TIMEOUT`, `RATE_LIMIT`, `INVALID_CONFIGURATION`, and `UNCONFIGURED` without leaking credentials.
- **Elimination of Warning Banner**: Completely resolved the error `"Voice synthesis temporarily unavailable (Sarvam Bulbul offline/unconfigured)"`. Audible playback through Sarvam Bulbul is verified end-to-end.

### B. Truthful Fail-Closed Voice Invariant
- Permanent ban on robotic browser speech (`window.speechSynthesis`).
- If unconfigured, TARKA displays rich textual findings and an explicit diagnostic notice with retry action rather than failing silently or falling back to robotic speech.

### C. Self-Contained Synthetic Demo Case (`upi_payment_discrepancy`)
- Bundled full synthetic fixtures in `data/cases/upi_payment_discrepancy/` with bank statement CSV, payment receipt PNG, WhatsApp chat log, and CDR records.
- Verified deterministic Z3 solver detection of a ₹10,000 discrepancy between the ₹25,000 bank debit and ₹15,000 screenshot claim.

### D. Repository Standardization & Friend-Ready Windows Setup
- Remote renamed to `Yaathrapalani/tarka` on GitHub.
- Authored beginner-friendly setup guide in `docs/GETTING_STARTED_WINDOWS.md`.
- Comprehensive configuration matrix in `docs/CONFIGURATION_REFERENCE.md`.

## 4. Security & Privacy Guarantees

1. **Epistemic Privacy**: Raw evidence bitstreams are **never** transmitted to third-party speech APIs. Only concise, structured investigative rationale generated by the local solver is sent for voice synthesis.
2. **Immutable Custody**: Every evidence ingestion is hashed via SHA-256 and appended to a cryptographic Merkle-linked SQLite custody ledger (`custody.db`).
3. **Statutory Authorization**: Consequential forensic actions (such as generating Section 63 BSA legal reports) require explicit confirmation gates and produce signed, tamper-evident audit records.

## 5. Known Limitations & Future Work

- **External Speech Dependency**: Audible voice playback requires a valid `SARVAM_API_KEY`. While offline mode provides complete textual reasoning, offline neural voice synthesis requires local TTS weights (planned for Wave 7).
- **Search Projection**: OpenSearch cluster integration is optional; in standalone native mode, keyword filtering over case artifacts operates via an in-memory index.
- **Production Cloud Deployment**: Zoho Catalyst serverless functions and production PostgreSQL clustering are documented for deployment in `docs/architecture/` but are optional for local development.
