# SentinelX --- Screen-by-Screen Specification

## Sign In

Purpose: secure entry. Success: **Sign in → Command Center**

## Command Center

Purpose: start/resume investigations. Click investigation → workspace.
Click alert → alert investigation. Click entity → preview/dossier. Click
evidence → viewer.

## Investigations

Search/filter by status, owner, date, priority and classification.
Row/card → Investigation Workspace.

## Investigation Workspace

Lenses: **Overview \| Network \| Timeline \| Map \| Evidence \| Entities
\| Findings**

Primary actions: - search - connect - verify - compare - save finding -
ask Sentinel

## Search

Search Person, Case, FIR, Phone, Vehicle, Location, Organization,
Evidence. Every result opens the correct destination.

## Entity Dossier

Identity, aliases, identifiers, cases, phones, vehicles, locations,
organizations, relationships, timeline, evidence, similar entities,
contradictions.

## Network

Expand, collapse, focus, isolate, shortest path, common connections,
compare, time and evidence filters. Node → preview/dossier. Edge →
relationship inspector.

## Relationship Inspector

Show entities, relationship, observed count, period, supporting sources,
evidence strength, contradictions and status.

## Timeline

Chronological events with entity/case/source/event/date filters. Click
event → context/evidence.

## Map

Incidents, movement, vehicles, locations, network activity and hotspots.
Click location → associated entities/events.

## Evidence Viewer

Document, source, hash/integrity, timestamp, uploader, classification,
chain of custody, extracted entities, related cases and graph links.

## Alerts

Critical / High / Medium / Low. Actions: acknowledge, assign,
investigate, dismiss, escalate.

## Watchlists

Wanted persons, missing persons, stolen vehicles, blacklisted vehicles,
persons of interest and authorized custom lists.

## Analytics

Network centrality, communities, trends, anomalies, temporal change and
spatial patterns. Every analytical result explains its basis where
material.

## Reports

Case summary, entities, timeline, network, evidence, relationships,
contradictions, AI leads, investigator findings, sources and audit
information.

## Data Sources

Source, connector, status, last sync, record count, freshness, errors,
owner and access level.

## System Health

API, database, graph, search, ingestion, AI, voice, storage and event
health.

## Audit

Filter by user, action, resource, time and result.

## Administration

Users, roles, permissions, policies, integrations, retention and audit
configuration.

## Help

Context-aware help. A graph question opens graph-specific guidance.

## Voice

Voice behavior adapts to current screen context and always updates the
visual workspace.
